# MTG-card-manager
Python-based desktop app for managing a Magic: The Gathering card collection using SQLite and Tkinter. Includes features for adding, searching, updating, and organizing card data through a user-friendly interface.

Features
- Add new cards to the database
- Search for cards by name or attributes
- Update existing card information
- Delete or manage card records
- Persistent data storage using SQLite
- User-friendly interface built with Tkinter
- Input validation to ensure data accuracy

Technologies Used
- Python
- SQLite
- Tkinter (GUI)

How to Run
- Install Python (if not already installed)
- Download or clone this repository
- Navigate to the project folder
- Run the program: python main.py
